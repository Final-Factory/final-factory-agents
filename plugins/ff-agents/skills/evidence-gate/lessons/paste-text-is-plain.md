# Text for the person to paste is plain

**Rule.** When you hand a person text they will paste (a Reddit post, an e-mail, Steam text, a
message to a friend), write it as plain text in the message: no code block, no Markdown, no
bullets they would have to strip. Write it the way they talk.

**Why.** Ben, 2026-10-02: "in general give me text that i need to paste that isnt code or
whatever in non formatted text". A code block copies with its own line breaks and font, and
Markdown markers land in the post. In the same week he sent back several ad headlines because
they did not sound like him: stiff constructions, and wording he called "kind of awkward".

**How to apply.**

- Code blocks only for commands and code.
- For Ben: short, plain, casual, first person as the developer, no marketing words or slogans
  (ff-marketing `brand/voice.md`; the `plain-writing` skill).
- Show the copy and get his sign-off before anything is sent or published. Publishing in a
  person's name is theirs to approve.
- One version to paste, not three to choose from, unless they asked for options.
