# Three visual pull requests, replayed against the gate (2026-10-02)

**In short:** given the Evidence section its own description supports, each of the three fails
`pr_evidence.py`. #913 fails on the pending review, #886 on the built player, and #884 on the one
thing its numbers could not show: that someone looked.

This is a dry run. No clip was re-watched and nothing was changed in the game repo. The inputs are
the three pull request descriptions as merged. None had an Evidence section, since the format is
new, so each fixture in `tests/fixtures/` is the section that pull request could honestly have
written from its own words, with "not stated" where the description is silent.
`tests/test_pr_evidence.py` keeps the results below true.

## #913, quick craft asks for an item a bot is carrying

Merged 37 minutes after it opened. Its description: "The `watch_video` review is pending on BEAST";
the clips are "the game's own frames at about 12 fps, resampled to 60" from the editor; the built
players are covered by stills.

```
$ pr_evidence.py --body-file tests/fixtures/pr-913-quick-craft.md
evidence-gate: FAIL (pr_evidence.py, the evidence-gate skill)
- something is still 'pending': no merge before the review is finished. Finish it, or move the claim it supports to 'Not verified'
- 'Built player: yes' is missing: a visual change is verified in a built player through the real event, not an editor rig. Until then it is changed, not fixed
- 'Clips' does not say where the event is (frames or seconds): a clip that does not contain the event proves nothing
- 'Looked: yes, ...' is missing: someone steps through the event's frames against the intended look. A measurement or a watch_video verdict is not a look
```

## #884, two players on one mobile station

This one had built players, twelve before-and-after clips, Ben's own words and a determinism
audit. Its proof of the main claim was a number: the other player's ship 0.0 units from its seat.
In the 0.50.0.64 build Ben found the rider still drawn with engine exhaust.

```
$ pr_evidence.py --body-file tests/fixtures/pr-884-station-riders.md
evidence-gate: FAIL (pr_evidence.py, the evidence-gate skill)
- 'Clips' does not say where the event is (frames or seconds): a clip that does not contain the event proves nothing
- 'Looked: yes, ...' is missing: someone steps through the event's frames against the intended look. A measurement or a watch_video verdict is not a look
```

The script cannot see exhaust. What it does is refuse the merge until the description names the
frames of the event and says someone stepped through them against Ben's sentence. That is the
step where exhaust on a seated rider is visible. A careless look can still miss it, which is why
the checklist also says to put the clip in the report when the person has caught the bug before.

  description.
