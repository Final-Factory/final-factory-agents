# Project memory: Editor & play mode traps

Part of the `project-memory` skill; links are relative to the skill directory. Add new
entries for this area here, one line each.

- [Raw ECS save bytes use Unity's layout](memories/raw-ecs-save-bytes-use-unity-layout.md) — validate saved stride with UnsafeUtility.SizeOf and decode with NativeArray.Reinterpret; Marshal Boolean widths can shift fields and invent apparent save corruption.

- [Play mode needs main scene](memories/playmode-needs-main-scene.md) — entering play mode hangs forever unless Assets/Scenes/main.unity is the active scene; check editor_state.active_scene first; a FRESH editor boot with no scene open instead looks wedged as an empty ~26-entity world under EditorApplication.Step()
- [No external edits to open Unity scenes](memories/no-external-edits-to-open-unity-scenes.md) — Write/Edit on an open .unity/.prefab raises a modal reload dialog that blocks the main thread and hangs the MCP bridge; edit via SerializedObject + SaveScene instead
- [DontSave bootstrap hosts outlive the editor play session](memories/dontsave-bootstrap-hosts-outlive-editor-play.md) — `new GameObject{hideFlags=DontSave}` + DontDestroyOnLoad survives play-mode exit; the next session's `_instance != null` early return reuses it with its runtime material destroyed (name tags drew nothing, 087); after a recompile a scene-less copy keeps running. Drop DontSave, keep DontDestroyOnLoad; find leaks with `Resources.FindObjectsOfTypeAll`
- [Unity keyword-remap shader crash](memories/unity-keyword-remap-shader-crash.md) — known Unity engine bug crashing import worker on ParticlesUnlit fallback keyword remap
- [wsay voice notifications](memories/wsay-voice-notifications.md) — global hooks speak via wsay when Claude finishes (Stop) or needs input (Notification); don't disable
- [Profiling ECS + fork pin bumps](memories/knn-profiling-and-fork-pin-gotchas.md) — Unity 6000.3.19f1/game revision `7d696256c` can record exact main-thread system markers with a qualified `ProfilerRecorder` recipe; samples are inclusive diagnostics, not additive production budgets; preserve the `ProfilerDriver` fallback; clone Packages/ can be a real dir: copy manifests + Client.Resolve() on the clone, verify PackageCache sha + fresh assembly mtime before trusting any run
- [Paired-leg preflight and editor wedges](memories/paired-leg-preflight-and-editor-wedges.md) — both editors must pass editor-preflight.sh (Burst enabled+drained, re-enable it first: the launcher leaves it off) before any leg, AND the first session after a forced recompile is a cold-Burst-cache warm-up whose forks are not the game's (074); the SIGBUS crash, the no-live-World wedge, the scene-changed-on-disk modal after a pull, the fresh-mtime rule for writing the client config, OutlivePairBreak + reclaim-identity files for rejoin legs
- [Build after the fast suite overwrote main.unity; git checkout of an open scene wedges BOTH editors](memories/build-after-fast-suite-overwrote-main-scene-and-open-scene-checkout-wedge.md) — the EditMode runner leaves its empty scene active and `BuildCommand2` saved it over `Assets/Scenes/main.unity` (guarded since 80386cea4 — still check the active scene before scheduling a build); restoring the file on disk while an editor had it open wedged the main AND clone editors (worktree symlink) on the native modal — shim + bridge time out, ~1% CPU; kill + `scripts/launch-editor.sh`
- [Procedural VFX draw gotchas](memories/procedural-vfx-draw-gotchas.md) — `tanh` of a large argument is NaN on Metal (clamp before an erf); per-frame SetFloat/SetBuffer on a Resources material writes into the .mat asset (use RenderParams.matProps); CompleteDependency() before an IJobEntity.Run() that reads LocalToWorld in presentation; ProfilerRecorder is blind in a stepped editor; rotated-frame culling bounds; real multi-structure mobile stations come from player blueprint JSON; `UNITY_MATRIX_P[1][1]` is negative under URP's intermediate texture, so use abs() for pixel-size math (VfxBeam still latent); execute_code tuning is lost on an editor restart unless explicitly saved
- [Transparent shader graph without depth write flickers](memories/transparent-shadergraph-without-depth-write-flickers.md) — a transparent-queue graph with constant alpha 1 (transparent only for Scene Color refraction) and ZWrite Control Auto sorts overlapping instances per object, which flips with the camera = the barge ice "z-fight" (fixed b334e573d with ForceEnabled); how to spot the class and the repro rig
- [Re-enabling an enableable component needs IgnoreComponentEnabledState](memories/enableable-component-toggle-needs-ignore-enabled-state.md) — a plain query over MaterialMeshInfo misses the disabled entities, so a hide/show toggle never shows them again (a perf probe left 720 renderers off, silently)
- [A shader's fragment stage must not re-derive a choice the vertex stage made](memories/shader-stages-must-not-rederive-a-geometry-choice.md) — the 0.50.0.58 white box beside ships (w139): the afterburner's exponential fade never reached 0, and at about 1e-36 the vertex stage drew the plume's screen box while the fragment stage read 0 and filled it with the nozzle's white; snap faded values to 0 below a floor, floor the value in the vertex stage and branch at half of it in the fragment stage, `nointerpolation` for per-instance values; sweep a pinned level down to 1.2e-38 to find one; an edited shader draws nothing in the editor until its variants compile
- [Play mode before the fast suite fails three locale tests](memories/play-mode-before-the-fast-suite-breaks-locale-tests.md) — `LocalOnlyCheatRefusalTest` x3, "SelectedLocale is null. Database could not get table.", after one play-mode session in the same editor; a restarted editor runs the suite clean
- [Editor UI screenshots at fixed sizes and in several languages](memories/editor-ui-screenshots-at-fixed-sizes-and-locales.md) — pick a `FixedResolution` Game view size by reflection (a custom size is lost on editor restart and its index then points elsewhere: look it up by w×h and check the PNG), the first frame after a size switch has no UI, drive size → locale → stage → `ScreenCapture` from a coroutine with ~20 frames between steps, clear `isPaused` first; lobby browser rows without Steam through `LobbyBrowser.ShowRows`; shoot Russian for width and CJK for baseline
- [A test job that failed to initialize fires on the next play](memories/failed-test-job-fires-on-next-play-mode.md) — `run_tests` right after a domain reload fails to initialize but stays queued; the next `play` shows `This cannot be used during play mode`, never reaches the main menu and leaves no scene open; stop, clear the stuck job, reopen `main.unity`, then play
